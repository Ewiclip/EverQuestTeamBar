# Team Bar guides

Team Bar is a free Windows application for arranging EverQuest buttons and spell overlays around your game windows. A button can send a different shortcut to each recipient. Each click runs its configured sequence once.

- [Set up your first button](first-button.md) to match characters to windows and connect a shortcut.
- [Arrange buttons and groups](button-groups.md) to build floating controls, dock them on a spell bar, or use just an icon.
- [Set up a spell overlay](spell-overlays.md) to track effects for a character and persona.
- [Configure API contributions](api-contributions.md) to send selected observations to EQTradeskills or a compatible service.

The screenshots show fictional game characters and sample settings. For installation and build instructions, see the [project README](../../README.md).
